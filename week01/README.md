# Wealth Odeh Personal Website

A simple, responsive HTML and CSS recreation of the visible content on:
https://wealth-odeh-personal-home.lovable.app/

## Files
- `index.html` — webpage structure and content
- `styles.css` — page styling and responsive layout

## Open in VS Code
1. Extract this ZIP file.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted `wealth-odeh-website` folder.
4. Open `index.html` in your browser, or use the Live Server extension if installed.

No npm install or build command is required.

Note: This is a clean recreation based on the content visible on the published site. The original site's private source code and exact styling/assets were not available, so this may not be a pixel-perfect copy.
