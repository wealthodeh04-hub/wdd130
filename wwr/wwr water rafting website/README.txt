WDD 130 MULTI-PAGE RAFTING WEBSITE

Files:
- index.html
- about.html
- trips.html
- contact.html
- wwr.css
- wwr.js

Open index.html in VS Code and use Live Server.

The pages are connected with normal relative links and share one CSS file, making the project suitable as a starting point for a WDD 130 rafting site.

For a fully offline version, download the referenced rafting images into an images/ folder and replace the remote image URLs with local paths.
